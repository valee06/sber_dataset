# Платежи по банковской выписке (Go)

Веб-приложение на Go: импорт реальной выписки СберБизнес (`.xlsx`), разбор платежей жильцов
и операций по счёту. Работает на localhost, **только на стандартной библиотеке Go** — внешних
зависимостей нет, `go mod download` не нужен.

## Запуск

Нужен Go 1.22 или новее.

```bash
cd gsk-payments
go run .                 # http://127.0.0.1:8080
go run . -seed           # то же, но сразу загрузить приложенную выписку в пустую БД
go run . -addr :9000     # другой порт
go run . -reset          # очистить БД перед запуском
go test ./...            # тесты разбора (в том числе на приложенной выписке)
```

Откройте <http://127.0.0.1:8080>. Запускать нужно из корня проекта (там лежит `data/sample`).

## Что умеет

| Раздел | Назначение |
|---|---|
| Главная | сводка: число операций, приход/расход, лицевые счета, доля привязанных платежей, последняя загрузка, последние операции |
| Платежи | поступления с фильтрами (год, месяц, лицевой счёт, категория, поиск), итоги, кнопка «Правка» |
| Операции по счёту | вся выписка (приход и расход), фильтры + направление, итоги и оборот |
| Импорт выписки | загрузка `.xlsx`, предпросмотр с чекбоксами и правкой л/с и категории, журнал загрузок |

**Сессия импорта.** Разобранная выписка хранится как черновик в `data/sessions/<id>.json`
(идентификатор — в cookie). Если закрыть страницу, черновик сохранится, а БД не меняется, пока
не нажата «Импортировать выбранные операции». Кнопка «Отменить» удаляет черновик.
Операции, уже имеющиеся в БД, помечаются «уже в БД» и не выбираются (защита от дублей).

## Как разбирается выписка

Файл СберБизнес состоит из листа-шапки (счёт, организация, период) и листа `operations`, где
каждое платёжное поручение занимает блок строк. Парсер (`xlsx.go`, `parser.go`):

1. читает `.xlsx` потоково (zip + encoding/xml), распознаёт даты по стилям ячеек;
2. находит блоки «ПЛАТЕЖНОЕ ПОРУЧЕНИЕ № …», берёт дату проводки, сумму («3500-00» → 3 500,00 ₽),
   плательщика, получателя, счета, КБК и назначение;
3. направление определяет по номеру счёта выписки: получатель = наш счёт → приход, иначе расход;
4. суммы хранит в копейках (`int64`), без ошибок округления.

`classify.go`: лицевой счёт (номер квартиры) берётся из назначения платежа («л/с 56», «кв. 161»,
«12-2-24», «ЛС 0000000134», просто «185» и т. п.), запасной вариант — адрес плательщика;
период оплаты — по названию месяца/«12,2017»; категория — по правилам (КБК → «Налоги и взносы»,
«зарплата» → «Зарплата», ресурсоснабжающие организации → «Коммунальные ресурсы» и т. д.).
Всё можно поправить вручную: такие операции помечаются тегом «вручную».

На приложенной выписке результат: **553 операции**, приход **413 на 3 471 733,16 ₽**,
расход **140 на 5 424 229,25 ₽**, к лицевым счетам привязано 379 из 413 поступлений (91%).

## Структура

```
main.go        запуск, флаги
server.go      маршруты и обработчики
store.go       файловая БД (data/db.json) и черновики импорта
xlsx.go        читалка .xlsx на stdlib
parser.go      разбор выписки СберБизнес
classify.go    лицевой счёт, период, категория
templates/     HTML-шаблоны (встраиваются в бинарник)
static/        CSS
data/sample/   приложенная выписка
```

## Замечания

* Хранилище — JSON-файл. Для учебного задания этого достаточно; если нужна «настоящая» БД,
  слой `DB` в `store.go` легко заменить на SQLite/PostgreSQL (`database/sql` + драйвер).
* Ожидается формат СберБизнес с листом платёжных поручений. Другой формат выписки даст понятную
  ошибку «в файле не найдены платёжные поручения».
